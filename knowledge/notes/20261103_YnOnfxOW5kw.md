# 김레터 — 스마트스토어 광고 끄기 전에 자연순위 확인법 (2026-11-03, YnOnfxOW5kw)
- 사례: 월 1,000~2,500만원 쓰던 쇼핑검색 CPC 광고(누적 ~1억, 광고 후에도 20~30% 이익)를 **1/30 수준으로 줄였는데 순위·매출 오히려 상승** — 자연순위를 함께 관리했기 때문.
- 광고를 끌지 말지는 **그날 메인 키워드로 직접 검색**해서 첫 화면(메인 지면)에서 내 상품이 **광고 칸 / 자연순위 칸에 몇 칸** 들어가 있는지 센다. (첫 화면의 광고:자연 칸 수는 키워드·날짜·사용자마다 다름)
  - 자연순위 칸에 있다 → 메인 키워드 월 광고비 ÷ 30 = 하루 얼마를 "이미 무료로 나오는 자리 옆에" 내고 있는지 보고 유지/축소 결정.
  - 자연순위 칸에 없다 → 광고는 유지하고 **자연순위 진입부터** 작업.
- 광고만 끈다고 순위가 오르는 것은 아님. 자연순위를 지킬 작업을 같이 해야 함.
