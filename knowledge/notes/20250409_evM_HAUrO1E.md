# 한드래곤 — 쿠팡 매출최적화 세팅~보고서 분석 (2025-04-09, evM_HAUrO1E)
- 광고 = **엔드 ROAS(손익분기) 계산 + 리뷰 확보**와 한 세트. 엔드 ROAS = 판매가 ÷ 1개당 순익 × 100 (예: 15,000 ÷ 5,000 = 300%).
  - ⚠️ 이 채널은 "크몽 리뷰 업체로 2~3개 작업"을 권하지만 **쿠팡 정책 위반 소지(대가성 리뷰) → 채택하지 않음**. 정책상 허용되는 체험단(쿠팡 체험단 등)만 검토.
- 매출최적화 = CPC 경매. AI가 키워드·입찰가를 자동 결정. 키워드의 **줄기 = 상품명 + 검색어(태그)**, 구매가 일어난 키워드에서 연관 키워드로 **가지**가 뻗어나감.
- **내 상품 본질 키워드(줄기)는 효율이 나빠도 제외 키워드로 넣지 말 것** (예: "임산부 ○○"를 제외하면 줄기를 자르는 것). 대신 상품 경쟁력·가격·상세·리뷰를 개선.
  - 제외 대상: 상품과 무관한 키워드, 관련은 있지만 결이 다르고 효율 나쁜 세부 키워드(예: 여행용 백팩인데 "비즈니스 백팩").
- 매출최적화 두 방식: AI 광고(전 상품 대상) vs **수동 상품 설정**(흔히 말하는 매출최적화).
- 전체 효율 < 엔드 ROAS 일 때: ① 엔드 ROAS 낮추기 = **원가 절감**(대량 수입, 구매대행 빼고 직수입, 더 싼 공장) ② 광고 효율 올리기.
- 검색 영역 효율 좋음 → 목표 ROAS ↓ / 비검색 효율 좋음 → 목표 ROAS ↑ (빌리브로 -ICQYJd0P0w 와 일치).
