# 호랑이커머스 — 쿠팡 광고 26년 최신판 (2026-10-21, 1sESZC1FSe8)
플랫폼: 쿠팡 · 주제: 상품효율지수, 손익분기(엔드) ROAS 전략

- 쿠팡 광고 노출 순서 = **CPC 입찰가 + 광고 적합도 + 인기도** 종합. 인기 상품은 낮은 CPC로도 좋은 구좌 노출.
- **상품 효율 지수** 확인법: 광고 만들기 → 매출 성장 → 수동 상품 설정에서 상품 추가 → 그래프 표시(최소 기준/권장 기준 선). 그래프가 안 차는 상품 = 광고 효율이 구조적으로 안 나오는 상품.
- 지수 올리는 법 = 많이·잘 파는 것. 모순 해결책 = **엔드 ROAS(손익분기 ROAS) 전략**: 초기엔 목표 ROAS를 광고 이익 0원 수준으로 설정해 판매량을 쌓는다 → 지수 상승 → 같은 비용으로 더 팔림.
  - 언제까지? 그래프 권장 기준(또는 가득 찰 때)까지 유지 → 이후 목표 ROAS를 **조금씩** 올려 광고에서도 이익 확보. 이 채널 평균 ROAS ~1000%.
  - 판단 근거: 광고 이익 0이어도 **자연 판매 포함 전체 이익**이 더 큼.
- 매출 = 노출 × 클릭률 × 전환율 × 객단가 (곱셈 → 하나라도 0이면 0). 광고는 노출 도구일 뿐, 상품 차별점·가격·상세페이지가 약하면 안 팔린다.
