# 셀레버리지 — 네이버 쇼핑검색광고 2026 세팅 + 애드부스트 조건 (2026-02-23, _JAOFYeRscw)
- 애드부스트는 **없는 매출을 만드는 게 아니라 이미 나오는 성과를 키우는 구조**. 조건 없이 쓰면 매출은 그대로, 광고비만 증가.
- 사전 세팅: 비즈머니 충전(1만원이면 충분), 비즈채널(쇼핑몰) 미리 등록·검수(몇 시간~하루), 프리미엄 로그 분석(스마트스토어는 자동).
- 구조: 캠페인(목적·예산) → 그룹(지면·CPC·그룹예산) → 소재(상품·문구·키워드). 쇼핑검색 캠페인은 **하루 3만원으로도 테스트 가능**.
- **애드부스트 병행 조건 3가지**:
  1. 쇼핑검색광고로 **구매가 꾸준히 나오는 상품**이 있을 것 (AI가 성과 상품을 자동 선별하므로)
  2. **하루 최소 5만원**을 무리 없이 쓸 수 있을 것
  3. 그 상태로 **최소 2주** 유지할 수 있을 것
- 대행사는 초반이 아니라 매출이 늘어 관리가 벅찰 때 쓰라는 조언.
