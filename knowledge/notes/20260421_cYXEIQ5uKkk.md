# 동비TV — 26년 4월 개편 네이버 광고시스템 완벽분석 (2026-04-21, cYXEIQ5uKkk)
플랫폼: 네이버 통합광고주센터(검색광고 + 디스플레이/GFA) · 주제: **어떤 숫자를 믿어야 하나**

## ⚠️ 가장 중요한 경고
- 2026-03-30 개편 후 기본 지표 **"총 전환 / 총 전환매출액 / 총 광고수익률"은 장바구니 담기를 포함**하고, 여러 광고 클릭에 **중복 집계**된다.
  - 예: 10만원 상품 1개 판매. 검색광고 클릭 → GFA 클릭 → 장바구니 → 구매 ⇒ 총 전환매출액 **40만원**으로 잡힐 수 있음 (실매출 10만원).
- **"총"이 붙은 지표는 성과 판단에 쓰지 말 것.** 대시보드도 구매 매출이 안 나오므로 비용 확인용으로만.
- 믿을 지표 = **총비용** + **구매완료 광고수익률(구매완료 ROAS)** + **구매완료 전환매출액/전환수**.

## 기여 전환 3종 (참고용)
| 지표 | 위 예시(장바구니 없이) | 용도 |
|---|---|---|
| 총 전환매출액 | 20만 (검색 10 + GFA 10) | 보지 말 것 |
| 기여전환(마지막 클릭) | 10만 (GFA) | 최종 구매를 만든 매체가 무엇인지 |
| 기여전환(데이터 기반) | 10만을 기여도로 배분 (비율 비공개) | 대략적 비중 감 |

## 화면 세팅
1. **전체 캠페인** → 열맞춤 설정(톱니) → "총" 지표 전부 해제 → **구매완료 광고수익률** 체크. (단 "총 전환매출액"을 빼면 상세데이터가 안 보이므로, 상세 보기를 원하면 총전환매출액 + 구매완료 ROAS 두 개만 켬)
2. 상세 데이터 → **전환 유형 구분** → 캠페인별 구매완료 금액 vs 장바구니 금액을 분리해서 볼 수 있음.
3. 필터로 **검색광고 / 디스플레이 분리**해서 본다 (메커니즘이 다름).
4. 구매완료 ROAS만 표시되므로 구매 매출 = 비용 × 구매완료 ROAS 로 역산.

## 키워드(검색어) 단위 관리 — 보고서
- 보고서 → 새 보고서: **캠페인 / 광고그룹 / 검색어** (소재 X — 소재 넣으면 검색어가 안 보임, "키워드" X — 파워링크 전용).
- 지표: 노출, 클릭, CTR, 평균CPC, (평균노출순위), **총비용, 구매완료 전환매출액, 구매완료 전환수**. "검색어별 전환 보고서 30일"로 저장 → 다운로드.
- 엑셀: 필터(Ctrl+Shift+L) → 비용 내림차순 → **ROAS = 구매완료 전환매출액 / 총비용** 열 추가.
- 판단: 손익분기 ROAS(엔드 ROAS)와 비교 → 적자 키워드는 **별도 그룹으로 분리 후 입찰 하향**, 흑자 키워드(예: 2,712%)는 입찰 상향. (예: 비용 36만/매출 63.7만=176% → 하향)
- 이 절차는 `tools/` 의 광고 리포트 분석기로 자동화 예정.
