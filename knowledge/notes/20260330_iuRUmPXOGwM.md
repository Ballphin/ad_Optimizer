# 셀러Jay — 쿠팡 로켓그로스 광고 왜 적자일까 (2026-03-30, iuRUmPXOGwM)
- 광고 세팅(ROAS·예산·제외키워드)을 몇 주~몇 달 바꿔도 적자 → **문제는 광고가 아니라 상품 경쟁력(가격·리뷰·옵션)**. 광고 = 노출 도구.
- 손익분기 판매량: 판매가 1만원, 마진 25%(2,500원), 일 광고비 3만원 → 하루 **12개** 팔아야 본전.
- 처방: 적자 상품은 광고를 **끄고** 가격/옵션을 경쟁력 있게 조정 → 광고로 이미 클릭했던 고객 풀 덕에 **자연 판매가 하루 2~4개** 나오면 좋은 신호 → 그때 다시 광고. 자연 판매가 없으면 광고로 해결 불가 → 추가 가격 조정/옵션 추가, 그래도 안 되면 정리(본전 처분).
