# 동비TV — 네이버 광고 간단한 설정으로 수익률 2배 (2025-10-22, o6jYSyld1yg)
플랫폼: 네이버 검색광고(쇼핑검색) · 주제: 예산 소진 시간 = 입찰가 조정 신호

- 네이버는 쿠팡과 달리 **수동 세팅이 자동보다 효율 좋음** → 자동광고 잘 안 씀.
- 핵심: 그룹/캠페인 **일예산이 24시간에 걸쳐 고르게 소진**되게 입찰가를 맞춘다.
  - 예: 예산 10만원, CPC 2,000원 → 50클릭 후 오전 11시에 소진 → 나머지 시간 노출 0.
  - CPC를 1,000원으로 낮춰 23시간 동안 소진 → 같은 돈으로 100클릭 → ROAS 상승 가능성. 실제 사례 ROAS 270~280% → 400 후반~500%.
- 방법: 통합광고주센터 → 내정보 → **알림 관리** → "캠페인 예산 도달 시", "광고그룹 예산 알림" 체크(+야간 21~08시 문자 수신).
  - 예산 도달 문자가 낮(13~14시)에 오면 입찰가 하향, 다음 날 19시면 조금 더 하향 → 자정 근처가 목표.
- 예외: ROAS가 충분히 좋으면(예: 400%+) 입찰을 내리지 말고 **예산을 늘린다**(10만→13만) 후 다음 날 재확인.
- ROAS가 목표 근처면 입찰가를 내려 평균 CPC를 낮추고 같은 예산으로 유입을 늘린다.
