# 트라이억 — 2026 최신 쿠팡 광고 세팅 운영 (2026-02-08, 8GQfoYV_xVw)
- **상품(키워드)마다 낼 수 있는 ROAS는 이미 정해져 있다** → 소싱/진입 전에 **키워드 입찰 단가**로 경쟁 강도 확인.
  - 확인법: 광고 만들기 → 매출 성장 → 상품 선택 → 직접 입력 → 키워드 추가 → 키워드별 입찰가 표시 (예: "양말" 5,430원 vs 세부 "기모 양말" 2,000원 미만).
  - 대표 키워드가 비싸면 회피하고 **세부(뾰족한) 키워드/상품군**으로 진입.
- **3일만 돌려보면 판가름**: 목표 ROAS 500%로 시작 → 안 돌면 300→200%로 내려봄 → 그래도 안 돌면 "빡센 키워드/상품". 500~1000%에서도 돌면서 팔리면 키울 상품.
- 쿠팡은 네이버와 달리 서브키워드부터 천천히 X, **초기(신상품 최신성 기간)에 밀어붙여야** 상위노출 기회. (주의: 이 채널은 '슬롯' 언급 — 우리는 정책 위반 수단은 제외)
- AI 스마트광고는 전 상품 통으로 돌림 → 특정 상품 키우기엔 부적합, **키울 상품은 매출최적화로 개별 캠페인**.
- 매출최적화 시작값(이 채널): 일예산 1~3만원(월매출 1~2천만 이하면 1만원), 목표 ROAS **500%**.
- 비검색 영역 소진 내역은 데이터가 거의 안 나옴 → 검색 키워드 보고서만으로 판단하면 한계.
