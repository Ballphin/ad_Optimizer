# 빌리브로 — 쿠팡 광고 ROAS 세팅법 (2026-09-23, -ICQYJd0P0w)
플랫폼: 쿠팡 매출최적화(목표 ROAS형) · 주제: 검색 vs 비검색 영역, 목표 ROAS 조정

- 쿠팡 광고 노출 영역 2개: **검색 영역**(검색결과 상단 '광고') vs **비검색 영역**(상품 상세 하단 "이런 상품은 어때요" 등). 상품마다 어느 쪽이 효율 좋은지 다르다 → 먼저 돌려보고 광고보고서로 영역별 광고비/매출 비교.
- **최소 7일은 세팅 변경 금지** — 쿠팡 광고는 AI 학습 싸움. 하루이틀마다 예산 축소/목표ROAS 상향 반복하면 광고가 무너진다.
- 목표 ROAS 조정 규칙(이 채널 주장):
  - **검색 영역** 매출이 더 크고 효율 좋음 → 목표 ROAS를 **낮춘다**(검색 노출 확대 의미). 단, 한 번에 크게 내리지 말고 100~500%p 폭으로 단계적으로.
  - **비검색 영역** 매출이 더 크다 → 목표 ROAS를 **높인다**.
- **제외 키워드 작업 주 1회 필수**: 광고보고서(광고 → 광고 보고서 → 기간/전체 캠페인 → 다운로드) 기준으로 비효율 키워드를 캠페인 수정 → 하단 "키워드 제외"에 등록.
  - 띄어쓰기 변형(예: "세탁기 받침대"/"세탁기받침대")은 별개 키워드 → 둘 다 넣는다.
- 가구매·트래픽 작업 하지 말 것, 최저가/핫딜로만 판 매출은 오래 못 감.
- 같은 상품(도매꾹 동일품)은 아이템위너에 묶이고 가격 치킨게임 → **차별화 상품**이 광고 효율의 전제.
- (주의) 채널이 자기 분석 프로그램/단톡방 홍보 → 1000% ROAS 주장은 그대로 믿지 말 것.
