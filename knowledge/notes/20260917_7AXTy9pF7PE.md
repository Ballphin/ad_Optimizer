# 동비TV — 어뷰징 없이 상위노출 SEO 40분 (2026-09-17, 7AXTy9pF7PE)
플랫폼: 네이버 · 주제: **최대한 많은 연관 키워드에 노출**시키는 구조

- 검색에 걸리려면 키워드가 다음 중 하나에 있어야 함: **상품명 / 속성(텍스트) / 카테고리 / 상점명 / 핵심 태그**. 일반 태그는 반영 안 될 수 있고 **"핵심 태그"만 확실히 반영**.
- 제약: 카테고리·속성·상점명은 각 1~2개 키워드만, 상품명 49자, 태그 10개 → 대부분 셀러는 연관 키워드 ~30개만 커버.
- 전략: 같은 상품을 **연관 키워드 60개에 노출**시키면 확보 가능한 월 검색량이 ~2배(예: 20만 → 38만). 경쟁사는 상위 메인 키워드에 몰리므로 **경쟁 약한 꼬리 키워드에서 상위 노출**이 쉬움.
  - 절차: 메인 키워드 연관검색어 전부 수집 → 쓸/안 쓸 키워드 분류 → 카테고리·속성·상점명·상품명·핵심태그에 **겹치지 않게 분배**.
- 채널 자체 툴(디뷰) 홍보 포함 — 툴 없이도 위 절차는 엑셀로 가능.
- 추가: 스토어 매출 대비 네이버 광고비 비율을 보고 다음 광고 예산을 정하라(통계 연동 기능 소개).
- 적용: 임산부 베개·올캠 각각 연관 키워드 표를 만들어 필드별로 배치 (`docs/` 작업 예정).
