# 상위노출 / SEO 플레이북

> 갱신 2026-11-22. 출처는 `knowledge/notes/<날짜>_<영상ID>.md`. 출처 없는 항목은 `[검증필요]`.

## 네이버
- 순위 공식 기준 1순위는 **검색어 적합도** → 상품마다 노릴 키워드 1개부터 정한다. (908KbYMVL4s)
- 키워드 선정 3기준: 적당한 월 검색량 / 1페이지에 리뷰 적은 상품이 섞임 / 1페이지 카테고리에 내 상품도 들어감. (908KbYMVL4s)
- 무료 최적화: 1페이지 상품과 **같은 카테고리·같은 속성**, 상품명에 키워드, 검색 태그(태그사전 등록돼도 실제 반영되는지 확인). (908KbYMVL4s)
- 자연순위 칸을 확보하면 광고를 크게 줄여도 순위·매출 유지 가능(사례: 광고비 1/30). (YnOnfxOW5kw)
- 순위의 큰 축은 **인기도(리뷰·구매·유입)**, SEO는 "안 맞추면 감점" 요소. 순위가 오를수록 SEO 중요. (qL1OtKL_QoU)
- **상품명 25~35자 권장, 최대 49자, 50자 넘으면 감점.** 같은 단어 중복 불필요(단어끼리 자동 조합). (qL1OtKL_QoU)
- 검색에 걸리는 필드: 상품명·속성·카테고리·**상점명**·**핵심 태그**(태그사전 등록 태그도 100% 반영은 아님). 점수는 상점명 > 상품명. (qL1OtKL_QoU, 7AXTy9pF7PE)
- **연관 키워드를 최대한 많이(예: 60개) 필드별로 겹치지 않게 분배** → 경쟁사가 비워둔 꼬리 키워드에서 상위노출, 확보 검색량 ~2배. (7AXTy9pF7PE)
- 가격비교 매칭 방지: 고유 모델명 사용. 묶이면 구성 차이 근거로 해제 요청. (g5cpPDsSzws, TAo-lmF7ifc)
- 플러스스토어는 기존 네이버쇼핑이 두 갈래로 나뉜 것 — 기존 노출·광고가 그대로 노출됨. 통합검색 내 플러스스토어 영역이 사용자 최다. (GUpK5TtJWy4)
- 정책 위반(가구매, 트래픽 작업) 금지 — 가구매 사기업체 경고(7eXqaSNLDYc), 트래픽은 돈만 날림(tLpTibzSY6s).

## 쿠팡
- 상품 등록 후 **검색어 필드를 자꾸 바꾸지 말 것** (품질지수 하락), 3주 관찰. (228C8VlKyys)
- 신상품 초기(최신성 기간)에 판매를 몰아서 만드는 것이 유리 — 단, 정상 수단(광고·외부유입·체험단)으로만. (8GQfoYV_xVw, -4-caU3NX1M)
- 외부 유입(쇼츠·오픈채팅) 상품을 쿠팡이 밀어준다는 주장. (-4-caU3NX1M) `[검증필요]`
- [검증필요] 아이템위너 확보(가격·배송·판매자 점수).

## 임산부 베개 — 고객이 실제로 고르는 기준 (9PjRiDI9IWg)
- 형태 비교: 일자형(굴러떨어짐) / U자형(저렴, 목 높이 조절 불가, 다리 올려도 떨어짐) / **H형(안 떨어짐, 어느 방향이든 받침, 폭 맞춤이 아쉬움)**.
- 결정 요인: **리뷰 수·인기순**, 블로그 후기. 6만원대도 감수.
- 필요 시기: **임신 16주 이후** 허리 통증 → 중·후기 필수.
- 좋았던 점으로 언급: 커버 분리 세탁, 알러지 방지 커버, 부드럽게 구부러지는 솜.

### 적용 아이디어 [검증필요 — 경쟁상품/우리 상품 확인 후]
- 대표 이미지: 옆으로 누운 임산부 + 핵심 차별점 1개("자다가 안 떨어져요" 등)를 크게.
- 상세페이지 첫 화면: 16주~ 주차별 사용 장면, 폭/높이 조절, 커버 분리 세탁, 소재 안전 인증, 출산 후 수유쿠션 활용.
- 키워드 군: 임산부베개 / 임산부 바디필로우 / H형 바디필로우 / 임산부 옆잠 / 임신 중기 허리 / 수유쿠션 겸용 / 출산선물.
- 리뷰가 적으면 대표키워드 광고 전환율이 낮다 → 세부 키워드 + 체험단(정책 준수)으로 첫 리뷰부터.
