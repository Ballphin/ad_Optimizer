# 쿠팡 광고 플레이북 (쿠팡 윙 / 로켓그로스)

> 상태: **초기 베이스라인**, 모든 항목 `[검증필요]`. "쿠팡 광고 교실", "한부장의 돈버는쿠팡", "돈벌자옹" 자막 수집 후 출처 추가.

## 0. 쿠팡 구조 이해
- [검증필요] **아이템위너**: 같은 상품(옵션)에 여러 판매자가 묶이면 위너만 노출됨. 위너가 아니면 광고 효율 급락. 카탈로그 매칭 상태 먼저 확인.
- [검증필요] 로켓그로스(쿠팡 풀필먼트) 여부가 노출·전환에 큰 영향. 판매자배송 대비 비용 구조(입출고·보관비)를 마진 계산에 반영해야 함.
- [검증필요] 쿠팡 판매수수료는 카테고리별 상이 (출산/유아동 카테고리 수수료율 확인 필요) + 광고비 VAT.

## 1. 매출 최적화 광고 (AI 스마트광고, 자동)
- [검증필요] 초기 학습용으로 자동 광고 → 2~4주 후 키워드 리포트에서 전환 키워드 추출 → 수동 캠페인으로 이관.
- [검증필요] 목표 광고수익률(ROAS) 설정형이면 손익분기 ROAS보다 높게 설정. 너무 높으면 노출이 거의 안 됨 → 단계적으로 조정.

## 2. 수동 키워드 광고
- [검증필요] 자동 광고에서 전환 나온 키워드만 수동으로, 키워드별 입찰.
- [검증필요] 자동 캠페인에는 수동으로 옮긴 키워드·비효율 키워드를 **제외 키워드** 처리 (중복 입찰 방지).
- [검증필요] 비검색 영역(상품 상세 하단 등) 노출 효율 따로 확인 후 OFF 여부 결정.

## 3. 광고 외 노출 요인
- [검증필요] 판매량·전환율·리뷰·가격·배송(로켓배지)이 자연 검색 순위에 반영. 광고로 판매량을 만들어 자연 순위를 끌어올리는 전략은 **광고 손실을 감수할 기간과 금액을 미리 정해야** 함.

## 4. 운영 루틴 (제안)
- 주 1회 키워드 리포트 다운로드 → `data/raw/` 에 저장 → 분석 스크립트로 손익분기 미만 키워드 추출 (추후 구현)
