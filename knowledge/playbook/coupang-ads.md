# 쿠팡 광고 플레이북 (쿠팡 윙 / 로켓그로스)

> 갱신 2026-11-22. 출처는 `knowledge/notes/<날짜>_<영상ID>.md`. 출처 없는 항목은 `[검증필요]`.

## 0. 원칙
- **목표 ROAS는 내 마진으로 정한다.** 쿠팡 담당자가 권하는 350%는 마진 28.6% 상품의 본전일 뿐. (Pb_wwIoBFT4)
- 광고는 노출 도구. 상품 경쟁력(가격·리뷰·옵션·상세)이 없으면 세팅을 아무리 바꿔도 적자. (iuRUmPXOGwM, -KVDOchQ3SM, 1sESZC1FSe8)
- KPI는 ROAS와 함께 **전체 매출 대비 광고비 비율**: 일반 10~15%, 10%면 우수, 20%+가 지속되면 위험. 장기 투자 상품만 초기 20% 허용. (228C8VlKyys)
- 같은 상품(동일 도매품)은 **아이템위너**에 묶이고 가격 경쟁 → 차별화가 전제. (-ICQYJd0P0w)
- 쿠팡 광고 노출 = **CPC 입찰 + 광고 적합도 + 인기도**. 잘 팔리는 상품은 낮은 CPC로 좋은 구좌. (1sESZC1FSe8)

## 1. 진입 전 점검
- **키워드 입찰 단가로 경쟁 강도 확인**: 광고 만들기 → 매출 성장 → 상품 선택 → 직접 입력 → 키워드 추가. 대표 키워드가 비싸면 세부 키워드/상품군으로. (8GQfoYV_xVw)
- **상품 효율 지수** 그래프 확인 (매출 성장 → 수동 상품 설정에서 상품 추가). 그래프가 안 차면 광고 효율이 구조적으로 안 나옴. (1sESZC1FSe8)
- 자연 순위가 최소 **1페이지 하단~2페이지 초반**은 돼야 광고 효율이 난다. (228C8VlKyys)
- 시즌이 짧은 상품엔 광고 투자 금지. (228C8VlKyys) — 임산부 베개는 시즌 상품 아님 → 투자 가능군.

## 2. 광고 유형 선택
- **AI 스마트광고** = 어떤 상품에 반응이 오는지 탐색용. **매출최적화** = 반응 확인된 상품을 개별 캠페인으로 키우기. (Pb_wwIoBFT4, 8GQfoYV_xVw, -KVDOchQ3SM)
- 수동 키워드 광고는 신중히 — AI→수동 전환 후 주문 끊긴 사례, 매출최적화만으로 충분하다는 사례. (-KVDOchQ3SM, 228C8VlKyys)

## 3. 목표 ROAS 운영
- 시작값 예: 일예산 1~3만원, 목표 ROAS 500%. 3일 돌려서 안 돌면 단계적으로 낮춰 본다. 낮춰도 안 돌면 "광고로 안 되는 상품". (8GQfoYV_xVw)
- 신상품: **손익분기(엔드) ROAS로 시작**해 판매를 쌓고 상품효율지수를 채운 뒤, 목표 ROAS를 **조금씩** 올려 광고에서도 이익. 광고 이익 0이어도 자연판매 포함 전체 이익이 기준. (1sESZC1FSe8)
  - 단, **손실 한도(금액·기간)를 미리 정하고** 시작. (Pb_wwIoBFT4)
- 높은 목표 ROAS로도 돌면서 팔리는 상품만 확대 대상. 아주 낮은 ROAS에서만 도는 상품은 광고비 빼면 남는 게 없는 상품. (-KVDOchQ3SM)
- **검색 영역 vs 비검색 영역**: 광고보고서로 지면별 광고비/매출 비교. (-ICQYJd0P0w, 채널 주장)
  - 검색 영역 매출이 크고 효율 좋으면 → 목표 ROAS를 단계적으로 **낮춰** 검색 노출 확대
  - 비검색 영역 매출이 크면 → 목표 ROAS **높이기**
  - 비검색 소진 내역은 데이터가 부족하니 맹신 금지. (8GQfoYV_xVw)
  - → `tools/ad_report.py --platform coupang` 지면별 요약

## 4. 학습 기간과 변경 규칙
- 학습 7~14일. 학습 중 **껐다 켜면 학습 초기화** → 끄지 않는다. 캠페인 성장 미션 충족 시 학습 완료율↑. (-DnxoTmKiIU)
- 설정 변경이 곧 전체 초기화는 아니지만, **예산(큰 폭)·목표 ROAS·상품** 변경은 재학습 유발. "진단 및 추천 → 성공 권장 사항" 반영 시 3일 내 학습 완료 가능. (75KwXLs3TpY, 2026-11 공식)
- 하루이틀마다 예산 축소·목표ROAS 상향을 반복하면 광고가 무너진다 → **변경 후 최소 7일 관찰**. (-ICQYJd0P0w)
- 광고 보고서를 매일 보며 일희일비 금지. 쿠팡의 "예산 올리세요" 권고도 내 손익 기준으로 판단. (228C8VlKyys)
- 상품 등록 후 **검색어(키워드) 필드를 자꾸 바꾸면 상품 품질지수 하락**. 안 팔려도 3주는 관찰. (228C8VlKyys)

## 5. 제외 키워드
- 주 1회 광고보고서(광고 → 광고 보고서 → 기간·전체 캠페인 → 다운로드) → 비효율 키워드를 캠페인 수정 → 하단 "키워드 제외"에 등록. **띄어쓰기 변형은 별개 키워드** → 둘 다. (-ICQYJd0P0w)

## 6. 광고비를 줄이며 매출 유지한 방법 (전환율 4.77% → 8.47%)
- 썸네일·상세·배너 교체, 가격을 **"싸게 보이게"** 포장, **묶음(2개·3개) 구매 유도로 객단가↑**. (228C8VlKyys)
- 적자 상품은 광고를 끄고 가격/옵션 조정 → 자연 판매가 하루 2~4개 나오면 광고 재개. (iuRUmPXOGwM)

## 7. 외부 유입으로 자연매출 키우기
- 쿠팡은 외부 트래픽을 끌어오는 상품을 밀어준다는 주장. 소형 유튜브 쇼츠(구독 1~2만, 쇼츠 평균 조회수 기준), 300~500명 오픈채팅방 방장 제휴. (-4-caU3NX1M)
- 임산부 베개: 맘카페·임신 출산 오픈채팅·임산부 크리에이터가 딱 맞는 타깃. **협찬 표기 필수**. `[검증필요]`
