# 사장님께 받아야 할 정보 (우선순위 순)

## 1순위 — 이것 없으면 아무 판단도 못 함
1. **상품별 판매가, 원가(매입가), 택배비, 포장비** — 옵션이 여러 개면 옵션별로. `data/products.example.json` 형식.
2. **채널별 실제 수수료율** — 스마트스토어 정산 내역 1건, 쿠팡 정산 내역 1건 (수수료 항목 캡처나 숫자).
3. **최근 30~90일 광고 리포트**
   - 네이버: 보고서 → 새 보고서 → **캠페인 / 광고그룹 / 검색어** + 노출수·클릭수·평균CPC·총비용·**구매완료 전환매출액·구매완료 전환수** (⚠️ "총 전환매출액"이 아니라 "구매완료"). 30일, CSV 다운로드
   - 쿠팡: 광고 → 광고 보고서 → 기간 30일·전체 캠페인 → 보고서 만들기 → 다운로드 (키워드·광고 노출 지면 포함된 것)
   - 지금까지 광고 성과를 **어떤 숫자(ROAS)로 보고 판단하셨는지**도 알려주세요 — 네이버 "총 전환" ROAS였다면 실제보다 크게 보였을 수 있습니다.
4. **같은 기간 전체 매출(광고 + 자연)** — 스마트스토어 통계, 쿠팡 윙 판매 통계. 광고가 자연 매출을 깎아먹고 있는지 판단용.

## 2순위
- 네이버 **애드부스트(ADVoost)** 사용 여부와 한 달 비용 / 쿠팡은 AI 스마트광고·매출최적화·수동 중 무엇을 쓰는지 / 목표 ROAS 설정값
- 상품 형태(H형/U형/일자형 등)와 경쟁사 대비 차별점, 현재 리뷰 수·평점 (네이버/쿠팡 각각)
5. 반품/교환율, 반품 1건당 비용
6. 쿠팡: 로켓그로스 사용 여부 (사용 시 입출고·보관비), 아이템위너 여부
7. 상품 URL (스마트스토어, 쿠팡) — 상세페이지·리뷰·경쟁상품 분석용
8. 주요 경쟁 상품 (알고 계시면)
9. 1억 손실의 구성 — 광고비가 대부분인지, 재고/원가 손실인지

## 3순위 — 자동화 단계
10. 네이버 검색광고 API (API 라이선스 / 비밀키 / 고객 ID) — searchad.naver.com > 도구 > API 사용관리
11. 네이버 커머스 API (애플리케이션 ID/시크릿) — apicenter.commerce.naver.com
12. 쿠팡 Open API (Access/Secret Key, 업체코드) — 쿠팡 윙 > 판매자정보 > 추가판매정보
    - 쿠팡 **광고** 데이터는 공식 API가 제한적이라 리포트 엑셀 업로드 방식이 현실적일 수 있음.

> 키는 채팅에 붙여넣지 말고, 세션의 보안 자격증명 입력창 또는 로컬 `.env` 로 전달 (커밋 금지).
