# API 키 전달 방법

## 원칙
- **키를 채팅창에 붙여넣지 마세요.** 대화 기록에 남습니다.
- 프로젝트 폴더에서 `.env.example` 을 복사해 `.env` 를 만들고, 텍스트 편집기로 값을 채우면 됩니다.
  ```bash
  cd "/Users/daniel/Desktop/01 Projects/Ad Optimzer" && cp .env.example .env && open -e .env
  ```
- `.env` 는 `.gitignore` 에 있어 GitHub(공개 레포)에 올라가지 않습니다. 저장 후 "넣었어"라고만 말씀해 주세요.
- 검색광고 API 키는 **입찰가·예산 변경 권한까지 포함**됩니다. Claude는 CLAUDE.md 안전 규칙대로 **조회만** 하고, 변경은 `docs/changes/` 에 안을 쓰고 승인받은 뒤에만 합니다.

## 1. 네이버 검색광고 API (광고 리포트 — 가장 중요)
1. searchad.naver.com 로그인 → 상단 **도구 → API 사용 관리**
2. "네이버 검색광고 API 서비스 신청" → 라이선스 발급
3. 화면의 **엑세스라이선스, 비밀키, CUSTOMER_ID** 3개를 `.env` 에 입력
- 이걸로 캠페인/광고그룹/키워드 구조, 일별 성과, 대용량 리포트(StatReport)를 받습니다.
- ⚠️ 2026-03 개편 이후 API 리포트가 **구매완료 전환을 장바구니와 분리해서 주는지** 첫 조회 때 확인합니다(cYXEIQ5uKkk). 분리 안 되면 광고센터 화면의 "검색어별 전환 보고서"를 CSV로 받는 방식과 병행.
- 애드부스트(GFA/ADVoost)는 검색광고 API와 별개 시스템이라 성과는 광고센터 화면에서 확인해야 할 수 있음.

## 2. 네이버 커머스 API (실제 주문·매출)
1. apicenter.commerce.naver.com → 스마트스토어 계정으로 로그인 → **애플리케이션 등록**
2. 권한: 주문 조회, 상품 조회 (변경 권한은 필요 없음)
3. **애플리케이션 ID / 시크릿** 을 `.env` 에 입력
- 광고 매출이 아니라 **스토어 실매출**을 봐야 애드부스트 ON/OFF 실험 등을 판단할 수 있습니다.

## 3. 쿠팡 Open API (주문·정산)
1. 쿠팡 윙 → 우측 상단 판매자명 → **판매자정보 → 추가판매정보 → OPEN API 키 발급**
2. **Access Key, Secret Key, 업체코드(Vendor ID)** 를 `.env` 에 입력
- 주문·상품·정산 조회용입니다.
- ⚠️ **쿠팡 광고(광고센터) 성과는 공개 API가 없습니다.** 광고 리포트는 계속 엑셀로 받아야 합니다:
  광고센터 → 광고 보고서 → 기간 30~90일, 전체 캠페인, **키워드·광고 노출 지면 포함** → 보고서 만들기 → 다운로드 → `data/raw/` 에 넣기.
